使用说明

平时怎么玩

直接在桌面上和他互动。

轻点一下他说一句和当前活动有关的话。正在看电视、玩手机或吃饭时，台词也会跟着变。

连续点他他会先躲开，再回嘴。一直不停手，会把他真正惹生气。

按住拖动把他搬到桌面上的其他位置。抓得太久或扔出屏幕，他会自己做出反应。

暂时不管他他会看电脑、玩手机、唱歌、吃饭或四处走动，不会一直站着不动。

提醒

闹钟与计时器可以设倒计时，也可以设每天或工作日重复。到点后，月云了会走到屏幕中间提醒，或者显示全屏提醒。程序退出后，所有提醒都会暂停。

台词

在台词工坊里选择一种情况，就能添加、修改和试听那时会说的话。写完后点“保存并使用”；满意的台词可以再导出一份备份。

找不到他，或者打不开

月云了跑丢了右键 99 图标，选择“移回屏幕中央”。

Windows 拦截安装包确认文件来自本站后，在提示中选择“更多信息”，再选择“仍要运行”。

macOS 拦截第一次打开确认文件来自本站后，到“系统设置 → 隐私与安全性”选择“仍要打开”。

仍然有问题打开“设置 → 导出诊断记录”，把生成的文件和看到的现象一起交给开发者。

开始使用！
