点他：从搭话到把他惹毛

关键不是点了多少下，而是你点得急不急。

隔一会儿轻点他会说下一句

如果他正在看电视、玩手机或唱歌，会先说那件事相关的台词。正在显示的气泡会直接换成新一句。

短时间快速连点他先往旁边躲

前几次不会回嘴，只会慢慢避开你的鼠标。

还不停手开始嫌你烦

躲够以后他会站住，表情变得不耐烦，并隔一会儿回你一句。

一直连续点彻底吵起来

回嘴会越来越凶，动作也会进入明显的生气状态。停下来让他缓一缓，怒气会慢慢退。

他睡着时不一样：短时间内连续点几下会把他吵醒，普通的生气次数不会在睡眠期间累计。

拖他：搬位置、拎起来与扔出屏幕

普通搬家很安静；抓着不放才会变成逗他。

按住并拖到别处月云了跟着鼠标移动。很快放下时，他只会站稳，不会每次都说话。
原地按住一会儿他会意识到自己被拎起来，开始晃动和挣扎。抓住身体的不同位置，摆动的样子也会不同。
拎到屏幕最上方他会挣扎得更明显，并警告你把他放下。聊天气泡会自动换方向，尽量留在屏幕里。
抓着一直不放他会持续回嘴，可能自己挣脱并走远。继续惹到极限，还会变成狐狸、冲撞屏幕并记仇。
拖到屏幕外再松手当身体大半不在屏幕里时，他会在外面待一会儿，然后自己走回来。反复这样做，回来时会骂得更凶。
真的找不到了：Windows 看任务栏右下角，macOS 看屏幕右上角，点击 99 图标后选择“移回屏幕中央”。

右键菜单：睡觉、提醒、葡萄和退出

在月云了身上点鼠标右键，会出现围着他的四个图标。

💤 / ☀️睡觉或唤醒

点月亮睡下后，他会安静、不再自言自语，之前的怒气也会放下。再次打开菜单点太阳、拖动他，或快速连点都能唤醒。

🌙闹钟与计时器

打开时间提醒窗口。这里可以新建、暂停、修改或删除提醒。

🍇喂葡萄

平时点它不会发生什么。只有他暴走后正在记仇时，葡萄才是让他恢复正常的办法。

×退出程序

会先询问你是否真的退出。退出后所有倒计时和闹钟都会暂停。

记仇时：左右键点他都只会听到气话，不能拖动；右键菜单也只剩葡萄。喂到嘴里以后他才会消气。

不碰他时：他也会过自己的生活

这些不是按钮，放着不管就有机会自己发生。

平常待着他会在看电脑、玩手机、看电视、走动、唱歌、不开心或烦躁之间慢慢切换，不会不停说话。

午饭时间大约在中午会先做饭，再坐下来吃饭。晚上吃过饭后，才可能自己喝红酒。

你一直在用电脑过了一段时间，他会觉得你在专心做事；如果很久没理他，偶尔会阴阳怪气地插一句。

你离开电脑电脑闲置一阵后，他会在桌面上探索，走走停停，偶尔变成狐狸。你一回来，他会立刻停下并变回人形。

很久没打开隔了好几天再见，他会记得这次久别，开场方式和平常启动不一样。

提醒：让他在该停下的时候来管你

右键月云了点 🌙，或从 99 图标选择“闹钟与计时器”。

倒计时

适合“25 分钟后提醒我”。可以直接选 5、15、25、60 分钟，也能自己填小时和分钟。运行中的倒计时可以暂停、继续或删除。

闹钟

适合“今天 18:30 提醒我”。可以只响一次，也可以设为每天或工作日重复。固定闹钟可以编辑、停用、重新启用或删除。

简单提醒到点后月云了会从原来的位置走到屏幕中间，问你是否知道了。点“好的”后他回原位；点“不要”会按你设定的时间再来一次。
强制提醒到点后直接显示占满屏幕的大号提醒，需要你点“我知道了”或按 Esc 关闭。
先预览在提醒窗口右上角点“5 秒后预览提醒效果”，不用真的等到闹钟时间。
退出会暂停：程序完全退出后不会在后台响。再次启动时，重复闹钟会继续计算下一次时间，已经错过的旧提醒不会突然补响。

台词工坊：决定每种情况下他说什么

从 99 图标打开“台词工坊”。左边选发生的情况，中间写台词，右边看触发说明和试听。

  1. 选情况

    例如“偶尔点他一下”“他在看电视”“被扔出屏幕后回来”。搜索框可以快速找到。

  2. 写台词

    点“新增一句”，输入想让他说的话。某些日常活动还能选平静、开心、嫌弃或得意的表情。

  3. 试听

    点“随便听一句”，月云了会在桌面上直接演给你看，不会因此真的生气。

  4. 保存并使用

    保存后立刻生效。关闭窗口前如果还有没保存的修改，程序会提醒你。

上一次 / 下一次在最近保存过的版本之间来回切换，最多保留最近 20 次。
叠加朋友的台词只把朋友文件里的新句子加进来；本机原有台词不会被覆盖，重复句子会自动跳过。叠加后还要点“保存并使用”。
保存到文件把满意的整套台词另存一份，方便备份或发给朋友。
恢复作者默认先把默认内容载入编辑器，确认以后再保存；仍然可以用“上一次”回去。
找回最近备份上次异常退出或台词文件损坏时使用。找到内容后，确认无误再点“保存并使用”。

设置与本机数据

点击 99 图标选择“设置”。目前只有真正需要的几项。

开机时自动启动他打开后，登录电脑时月云了会自动出现。macOS 还可以在“系统设置 → 通用 → 登录项”里管理。
查看使用引导重新打开第一次见面时的欢迎页。
导出诊断记录遇到问题时保存一份说明文件交给作者。它会记录程序状态，但不会放入台词正文、提醒正文或完整的本地路径。
卸载不会自动删掉你的内容：覆盖安装或普通卸载时，自己写的台词、提醒和设置会继续保留在这台电脑上。

找不到他，或者哪里不对

先按下面顺序处理，通常不用重新安装。

先找入口

Windows 查看任务栏右下角和“^”折叠菜单；macOS 查看屏幕右上角菜单栏。

移回中央

点击 99 图标，选择“移回屏幕中央”。显示器拔插或分辨率变化后也可以这样做。

检查是否睡着

睡眠时他不会自言自语。右键点他，看菜单里是不是太阳图标。

导出记录

仍然异常时，从“设置”导出诊断记录，把文件和你看到的现象一起发给作者。
