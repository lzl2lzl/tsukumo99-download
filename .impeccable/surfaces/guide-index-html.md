scope: `guide/index.html` and `guide/features.html`; visitor mode: Read.

Audience: 二次元同好与学生用户。大多数人只扫读，需要在半分钟内知道“在哪里点、会发生什么”；少数认真读的人需要完整、可信的触发说明。

Job: 从下载、安装、第一次打开一路走到会互动、会设置提醒、会改台词、会找回桌宠和数据。每段只使用普通用户语言。

Direction: “动作 → 反应手册”。文档首页是一条极短的上手路线，并把所有功能入口收敛为“右键月云了”和“右键 99 图标”两个选择；详细页按“我做什么”组织，而不是按软件内部模块组织。深紫夜色、奶白文字、99 图标和人物素材继承下载页。

Memorable moment: 两张并列入口卡分别演示角色右键圆盘和 99 托盘入口；托盘卡同时放大 Windows 紫色图标、macOS 黑白图标，并用隐私打码实图交代 Windows 右下角位置。

Constraints: 正式产品文档口径、版本无关；下载页继续如实显示当前安装包版本和签名状态；不写代码术语；不虚构截图；手机与键盘可完整使用。
