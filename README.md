「月云了桌宠」Windows 与 macOS 的公开下载页、宣传图与版本文件。

- 下载页：<https://lzl2lzl.github.io/tsukumo99-download/>
- 快速开始：<https://lzl2lzl.github.io/tsukumo99-download/guide/>
- 完整功能手册：<https://lzl2lzl.github.io/tsukumo99-download/guide/features.html>
- 历史版本：<https://github.com/lzl2lzl/tsukumo99-download/releases>

本仓库不包含项目源代码。

下载页会从 GitHub Releases 自动读取最新版本，并为 Windows 与 macOS 分别匹配安装包。产品文档采用不依赖具体版本号的正式说明，下载页则始终如实显示当前安装包的版本与签名状态。三个页面均适配电脑和手机浏览器。
